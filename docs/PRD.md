# Product Requirements

Build a local CLI that turns agent workflow fixtures into executable or dry-run smoke evidence.

## Users

- Agent skill maintainers preparing release candidates.
- Connector authors validating side-effect boundaries.

## Requirements

- Load JSON fixtures.
- Generate smoke plans.
- Run explicitly executable local commands.
- Block fixtures with forbidden side effects.
- Render JSON and Markdown evidence.
- Include tests, smoke command, validation script, and skill guide.
